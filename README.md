# Booking Management React Frontend

## Requirements
- Node.js 18 or newer
- npm

## Run
1. Extract this ZIP.
2. Open the extracted `booking-management-react` folder in VS Code.
3. Open Terminal in VS Code.
4. Run `npm install`
5. Run `npm run dev`
6. Open the localhost URL printed in the terminal (usually http://localhost:5173).

## Features
- Create, read, update and delete bookings.
- Search by student, parent, phone or booking ID.
- Filter bookings by status.
- View booking details and change status (Pending / Accepted / Rejected / Enrolled).
- Upload payment slip (JPG, PNG, WEBP or PDF; maximum 3MB).
- Booking data is saved in browser localStorage.

## Notes
This is a frontend-only demo. Data is stored in the current browser's localStorage, not in a server/database. The sample records are demo data. Payment confirmation, Zoom links, authentication and real payment processing are not connected to a backend.
